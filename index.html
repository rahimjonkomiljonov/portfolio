01 / About

A bit about me

I'm a student at Gachon University and a self-driven developer. My path began with Python: small tools like a password manager, a Pomodoro timer and a habit tracker taught me how to break a problem into parts and finish it.

Today I build larger things. I've shipped a campus dating app with Next.js, a live audience-polling platform on Supabase, and a stock-portfolio widget for both Windows and Android. I like products where the details are right: clear UI, sensible data, and code that I can explain.

My GitHub motto is simple: create everything with Python, and reach for other tools when the job needs them.
